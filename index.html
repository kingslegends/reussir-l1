Questions fréquentes

Avant d'acheter

Est-ce que je peux voir le contenu avant de payer ?

Oui : l'extrait gratuit de 50 pages montre des pages de chaque partie (cours, exercices, sujets, corrigés). Lis-le d'abord, puis décide.

Comment je lis le guide après l'achat ?

Va dans « Mon livre » et saisis ton code personnel. Le guide s'ouvre dans ton navigateur, sur téléphone comme sur ordinateur. Ton code reste valable : tu peux revenir lire quand tu veux.

Est-ce que je peux télécharger le PDF ?

Non. Le guide se lit sur le site, avec ton nom sur chaque page. C'est ce qui permet de le vendre à petit prix : si on pouvait le partager librement, il n'existerait pas.

Et les corrigés des exercices ?

Les 31 examens sont entièrement corrigés. Les corrigés des exercices arrivent par mises à jour, gratuites pour les acheteurs : ils apparaîtront directement dans ton espace.

On peut acheter à plusieurs ?

Oui : à partir de 5 étudiants qui achètent le guide complet ensemble, c'est 3 500 F chacun au lieu de 5 000 F. Écris sur WhatsApp pour organiser le groupe. Chaque étudiant reçoit son propre code.

Je peux donner mon code à un ami ?

Non. Le code est personnel et ton nom apparaît sur chaque page. Un code partagé est désactivé.

C'est un document officiel de l'université ?

Non. C'est un guide indépendant, écrit par un étudiant, pour aider à réviser. Il ne remplace pas les cours de tes enseignants.
